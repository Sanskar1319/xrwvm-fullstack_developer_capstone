# Cars Dealership - Full Stack Web Application

## Project Overview
**Cars Dealership Application** is a comprehensive, production-ready full-stack cloud application developed as part of the IBM Full Stack Software Developer Capstone Project. The application enables customers across the United States to browse nationwide car dealership branches, view available vehicle makes and models, read verified customer reviews with AI-powered sentiment analysis, and post their own dealership reviews.

## Architecture & Technologies
- **Frontend:** React.js, HTML5, CSS3, Bootstrap 5, JavaScript (ES6+)
- **Backend Application Server:** Python / Django Web Framework
- **Microservices & Database Services:**
  - Node.js Express & MongoDB for Dealership and Customer Reviews Service
  - Python Flask & Watson NLP for Review Sentiment Analysis Service
  - SQLite database for Car Models and Car Makes
- **DevOps, Containerization & CI/CD:**
  - Docker containerization for microservices
  - Kubernetes / OpenShift deployment manifests
  - IBM Cloud Code Engine serverless deployment
  - GitHub Actions for continuous integration, linting, and testing

## Key Features
1. **Nationwide Dealership Directory:** Filter and search dealership branches across all 50 states.
2. **Dealer Reviews & Sentiment Analysis:** Integrated microservice evaluating customer sentiment (Positive, Neutral, Negative).
3. **Vehicle Catalog:** Complete listings of car makes and models with technical specifications.
4. **Authentication & User Management:** Secure registration, login, logout, and session handling.
5. **Admin Portal:** Django Administration dashboard for managing car makes, models, and dealer data.
